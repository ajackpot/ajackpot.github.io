# Step 34. 댓글 공통 본문 바로가기와 홈 진행 상태 문구 개선

## 1. 변경 범위

- 댓글 목록 두 비교안의 글로벌 메뉴 탐색 비용 제거
- 댓글 목록 가상 벤치마크 재계산
- 홈과 최종 결과 화면의 설문 연결 영역 문구를 진행 상태에 따라 변경
- 관련 자동 검사와 수동 점검표 보강

## 2. 댓글 목록 본문 바로가기

댓글 과업 수행 페이지의 첫 번째 초점 항목으로 `본문 바로가기` 링크를 추가했다. 문제 페이지와 개선 페이지에 같은 링크를 제공하며, 실행하면 글로벌 메뉴를 건너뛰고 `정렬과 범위 선택` 제목으로 이동한다.

이 변경은 글로벌 메뉴 탐색을 A/B 차이에서 제외하고, 조건 선택 방식, 댓글별 반복 작업, 대화상자 복귀 방식에서 생기는 부담을 중심으로 비교하기 위한 것이다. 페이지 아래쪽의 `댓글 목록으로 이동` 버튼은 기존처럼 측정 제외용 보조 동작으로 유지한다.

## 3. 댓글 목록 가상 벤치마크

두 비교안의 두 과업 모두 첫 단계에 `skip-to-main`을 반영했다. 문제 페이지에서는 글로벌 메뉴 전체를 지나던 단계를 제거했고, 개선 페이지의 두 번째 과업에는 기존에 빠져 있던 본문 바로가기 조작을 명시적으로 포함했다.

| 사용자 유형 | 문제 페이지 기존 | 문제 페이지 변경 | 개선 페이지 기존 | 개선 페이지 변경 | 변경 후 예상 감소 |
|---|---:|---:|---:|---:|---:|
| 키보드 사용자 | 116.2초 | 102.0초 | 28.6초 | 30.2초 | 71.8초(70.4%) |
| 화면낭독 사용자 | 203.3초 | 180.5초 | 47.7초 | 50.5초 | 130.0초(72.0%) |
| 스위치 사용자 | 286.7초 | 255.5초 | 70.3초 | 75.0초 | 180.5초(70.6%) |

문제 페이지의 예상 시간은 글로벌 메뉴 비용을 제외하면서 감소했다. 개선 페이지는 첫 과업 값은 유지되고, 두 번째 과업에 공통 바로가기 조작을 명시하면서 소폭 증가했다. 따라서 변경 후 비교값은 댓글 목록 내부 구조의 차이를 이전보다 더 직접적으로 반영한다.

## 4. 테스트 진행 상태 문구

설문 연결 영역은 저장 상태에 따라 다음처럼 표시한다.

| 상태 | 상단 문구 | 제목 | 핵심 안내 |
|---|---|---|---|
| 저장된 과업 없음 | 테스트 준비 | 테스트 진행 상태 | 서비스를 골라 테스트를 시작하도록 안내 |
| 일부 과업 또는 서비스 완료 | 테스트 진행 중 | 테스트 진행 상태 | 남은 서비스 수와 설문 이동 조건 안내 |
| 세 서비스 완료 | 테스트 완료 | 설문 작성하기 | 수행 기록이 입력된 설문으로 이동 안내 |

완료 전에는 `테스트 마무리`, `테스트를 마치고 설문 작성하기`를 표시하지 않는다. 일부 서비스가 남아 있으면 `1개 서비스의 남은 과업을 마치면 설문지로 이동할 수 있습니다.`처럼 남은 수를 문장에 반영한다.

## 5. 검증

다음을 자동으로 확인한다.

- 댓글 두 비교안에서 본문 바로가기가 글로벌 메뉴보다 먼저 렌더링되는지
- 바로가기 대상과 초점 이동이 `정렬과 범위 선택`으로 연결되는지
- 네 개 댓글 벤치마크 과업에 공통 바로가기 단계가 포함되는지
- 댓글 벤치마크 결과 파일이 변경된 그래프와 일치하는지
- 준비, 진행 중, 완료 상태별 문구가 올바르게 바뀌는지
- 완료 전 화면에 마무리 문구가 남아 있지 않은지

`npm run benchmark`와 `npm run check`를 통과했다. 실제 화면낭독기에서는 첫 Tab으로 `본문 바로가기`가 읽히는지, 실행 후 글로벌 메뉴를 건너뛰고 본문 시작점으로 이동하는지 수동 확인한다.
