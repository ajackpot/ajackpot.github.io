# 35단계 설문 미리 입력 URL 길이 축소 보고서

## 문제

세 서비스의 비교안 A/B 수행 기록 6개에 사용자 유형별 사전 예상 시간과 실제 시간의 차이를 반복해서 넣으면서, URL 인코딩 뒤 Google Form 미리 입력 주소가 지나치게 길어져 400 오류가 발생할 수 있었다.

## 수정

`lib/survey-link.js`에서 설문 자동 응답값에 넣던 다음 내용을 제거했다.

- `사전 예상 시간과 실제 시간의 차이` 제목
- 키보드 사용자 예상·실제 시간과 차이
- 화면낭독기 사용자 예상·실제 시간과 차이
- 스위치 사용자 예상·실제 시간과 차이

설문에는 다음 정보만 전달한다.

- 비교안 A/B
- 실제 페이지 유형
- 실제 수행 합계
- 과업별 실제 수행 기록

사전 예상 기준과 실제 시간의 차이는 최종 결과 화면, 브라우저 저장 기록, 내려받는 결과 파일에서 계속 확인할 수 있다.

## 검증

동일한 대표 수행 기록으로 만든 URL 길이는 11,912자에서 6,984자로 줄어 4,928자(41.4%) 감소했다. 회귀 검사에서는 여섯 개 자동 응답값에 예상 시간 문구가 없는지, 페이지 유형과 실제 기록은 유지되는지, 최종 URL이 8,000자보다 짧은지 확인한다.
